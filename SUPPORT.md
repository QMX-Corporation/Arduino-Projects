# Support

Need help with a project, having trouble compiling an Arduino sketch, or experiencing an issue with the repository? We are here to help!

---

## Where to Get Help

### 1. GitHub Issues
If you found a bug in an existing project, encounter an issue with the repository structure, or want to request a new feature:
* Open an **Issue** using our predefined templates (`bug_report.md` or `feature_request.md`).
* Please provide clear details, such as your Arduino board model, error logs, and steps to reproduce the problem.

### 2. Project-Specific Readmes
Before asking for help, make sure to check the specific `README.md` inside each project folder. Many projects include:
* Hardware wiring diagrams and pinouts.
* Required external libraries.
* Specific instructions for compilation and upload.

### 3. Community Discussions & Pull Requests
If you are collaborating on a Pull Request or want to discuss improvements to someone else's project:
* Use the comment section directly in the **Pull Request** to talk with the author and maintainers.

---

## Asking Good Questions
When asking for help, please remember to:
* **Be clear and descriptive:** State what you expected to happen versus what actually happened.
* **Include code snippets or logs:** Share the exact error message or code segment causing the issue.
* **Specify your hardware:** Mention if you are using an Arduino Uno, Mega, Nano, or other microcontrollers, as well as any sensors involved.

Thank you for being part of our community and keeping open-source hardware alive and collaborative!
