# Security Policy

## Supported Versions
Since **Arduino-Projects** is a community-driven collection of open-source Arduino code, firmware samples, and examples, security updates and patches are applied to the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | ✅ |

---

## Reporting a Vulnerability
If you discover a security vulnerability, a flaw in code submission mechanisms, or any malicious code within a contributed project, please report it responsibly.

* **Do NOT open a public GitHub Issue** for security vulnerabilities.
* Instead, please report them directly by opening a private discussion or contacting the maintainers through the repository channels.
* Include a detailed description of the vulnerability, steps to reproduce it, and potential impact.

We take the safety of our community and hardware devices seriously and will work swiftly to address valid reports!
